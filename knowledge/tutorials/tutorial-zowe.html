    Preparação do Ambiente

    Passo 1: Instalação Visual Studio Code

    O VS Code servirá como a IDE padrão para suporte aos plugins Zowe, MF Helper e HUB de IA.

    1
    Acesso ao Portal da Empresa: Entre no portal corporativo a partir da sua estação de trabalho.
    2
    Pesquisa e Instalação: Pesquise pelo aplicativo VS CODE (Visual Studio Code) e clique em instalar.

    Passo 2: Habilitação de Acesso ao Zowe

    Para utilizar o Zowe, solicite acesso com o identificador corporativo <userid>.

    1
    Abertura da solicitação: Acesse <corporate-access-portal> para solicitar acesso para <userid>.
    Preencha os campos exatamente como abaixo:
    • Categoria de Serviço: <service-category>
    • Tipo de Solicitação: <request-type>
    • Ambiente: <environment>
    • Descrição: <approved-request-wording-for-userid>

    Configuração do Zowe

    Passo 3: Configuração da Extensão Zowe

    Com o VS Code instalado e o acesso liberado, vamos instalar e configurar a extensão do Zowe Explorer.

    1
    VS Code Extensions: Acesse o marketplace de extensões (barra lateral), pesquise por Zowe Explorer e instale.
    2
    Painel Zowe Explorer: Após a instalação, clique no ícone da extensão Zowe na barra lateral esquerda do VS Code.

    Diretório Local e Arquivos de Configuração

    Os arquivos precisam ser salvos na pasta local do usuário:

    C:\Users\[seu_usuario]\.zowe
    • Arquivo zowe.schema: Manual de regras que validam as propriedades e garante tipos corretos.
    • Arquivo zowe.config: Contém os perfis de conexão do ambiente <organization>.

    Passo 4: Autenticação e Credenciais Zowe

    Conexão Mainframe via Zowe Explorer.

    1
    Na seção DATA SETS, conecte ao perfil zosmf, clique no ícone da lupa e informe <userid> e a credencial corporativa autorizada.
    Dica de Uso: Após a autenticação, o acesso aos particionados é feito pela área de Data Sets. O sysout dos jobs executados serão exibidos na área de Jobs logo abaixo.

    Referência Rápida de Bibliotecas

    Relação rápida de bibliotecas para facilitar a navegação no Mainframe:

    Passo 5: Ajuste de Proxy (Tratamento de Erros)

    Resolução de erro de Comunicação HTTP.

    Erro conhecido: Caso ocorra a mensagem Failed to send an HTTP request, ajuste as configurações de proxy conforme abaixo.
    1
    Acessar Settings: Abra o menu de configurações do VS Code pressionando Ctrl + ,.
    2
    Pesquisar por Proxy: Na barra superior de busca das configurações, digite "Proxy".
    3
    Http: Proxy: Preencha o campo com o endpoint aprovado: 
    https://<zosmf-host>
    4
    Http: Proxy Support: Mude o valor de override para off.

    Extensões Adicionais

    Passo 6: Instalação das Extensões VSIX & GIT

    Como estas extensões são corporativas locais, realizaremos a instalação via arquivo .vsix.

    1
    Acessar Extensões: Abra a aba de Extensões pressionando Ctrl + Shift + X, clique nos três pontos (...) no topo, depois em Install from VSIX....
    2
    Instalar MF Helper: Selecione a extensão do MF Helper.
    3
    Instalar HUB de IA: Repita o mesmo processo para a extensão do HUB de IA.
    Observação: Instale a versão aprovada; versões incompatíveis podem falhar ao acessar <internal-package-registry>.
    4
    Reiniciar IDE: Logo após as instalações, reinicie o VS Code.

    Instalação do GIT

    O Git é o motor de controle de versão instalado no seu sistema operacional. Embora o VS Code seja o editor de código (a interface visual onde você escreve e edita os arquivos), ele não gerencia o versionamento sozinho. A função desse programa dentro do VS Code é servir como a tecnologia principal que possibilita todas as ferramentas de controle de código da IDE.

    GitHub Copilot

    Passo 7: Solicitação de Acesso ao GitHub Copilot

    Licenciamento através de <corporate-license-portal>.

    Pré-requisito: É necessário possuir acesso a <required-corporate-routine>.
    1
    Acesso ao Portal: Acesse <corporate-license-portal> e selecione a opção de licenciamento do Copilot.
    2
    Informe <corporate-email> em "Email solicitante".
    3
    Informe o e-mail do seu gerente, gerente departamental ou superintendente em "Email do gerente".
    4
    Clique em "Validar" ao lado de "Email do gerente". Este processo irá validar se o e-mail informado pertence a um gerente, gerente departamental ou superintendente. Se sim, os dados "Nome do gestor" e "Departamento" serão preenchidos.
    5
    Selecione o centro de custo em "Selecione o centro de custos referente ao seu departamento".
    6
    Informe a justificativa da sua necessidade de uso e envie a solicitação.
    Acompanhamento: Acompanhe a solicitação em <corporate-access-portal> e valide a aprovação pelo SSO de <organization>.

    Passo 8: Autenticação e Conexão do Copilot Business

    Validação do Acesso Corporativo no VS Code.

    1
    Conexão: Clique no ícone do Copilot e faça login com <corporate-email>.
    Logoff de Conta Pessoal: Se houver uma conta pessoal ativa no VS Code, faça Sign Out na aba de contas antes de prosseguir.
    2
    Acesso Business: Clique no ícone do Copilot no canto inferior direito e faça login com a conta business.
