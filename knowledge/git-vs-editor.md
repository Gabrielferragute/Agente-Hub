## Diferença entre VS Code e Git

- **Git** é o motor de controle de versão (como o Endevor/ChangeMan). Fica instalado na sua máquina, controlando os arquivos.
- **VS Code** é apenas o editor visual que tem botões para não precisar digitar comandos do Git.
- `Commit`: Salva versão local.
- `Push`: Envia para o repositório central.
- `Pull`: Puxa atualizações do time.
